# OctoAcme Project Management Docs

This repository contains OctoAcme's project management process documents. This README is an entry point that summarizes the program's approach and links to the detailed process documents in the docs/ folder.

## Quick summary
OctoAcme follows an iterative, customer-first project management approach with clear roles (PM, PdM, Developers, QA), a lightweight initiation (one-pager), planning with a prioritized backlog and Definition of Done, execution with regular standups and PR-based workflows, and continuous improvement via retrospectives and tracked action items. Emphasis is on measurable outcomes, risk management, and clear communication cadence.

## How to use
- Read the overview and initiation guide first for context and roles.
- Use the planning doc when moving approved initiatives into backlog and release planning.
- Follow the execution & tracking doc for day-to-day workflows, PR guidelines, and QA.
- Use the retrospective doc to capture improvements and convert action items into backlog issues.
